# Decisions

- The first delivery is a web PWA because it runs on iPhone without a Mac or App Store
  account. A native wrapper can be added later.
- Practice mode is the default until the owner supplies real Zoho credentials.
- Money is represented as opaque text in the app. The mock is the only component allowed
  to calculate practice totals.
- The supplied videos are treated as visual references, not copied assets. The app uses
  an original glass, depth, glow, and nature-inspired motion language.
