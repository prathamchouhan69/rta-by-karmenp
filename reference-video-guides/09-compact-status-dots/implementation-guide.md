# Video 09 — Compact status dots

## My question and answer

**Question:** Where should the status-dot treatment appear?

**My direction:** Show status dots anywhere tasks or systems show status, but
only in compact spaces.

## Implementation guide

- Use dots only where a status already exists and the compact layout benefits.
- Pair each dot with readable status text or an accessible label; never make
  color the only status signal.
- Reuse consistent status meanings and colors across the product.
- Do not add decorative dots or use this as a reason to invent status data.
