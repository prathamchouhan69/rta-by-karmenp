# Video 01 — Interaction controls

## My question and answer

**Question:** Which parts of this reference should influence the app, and how
should its controls, motion, and colors be adapted?

**My direction:** Adapt all relevant control types—buttons, checkboxes, toggles,
selects, and charts—and their motions. Keep motion subtle and trigger it only
on tap or state change. Keep KARM indigo and brass; do not use the reference's
lime.

## Implementation guide

- Apply only the control patterns that fit an existing RTA by KARM screen.
- Give each control clear idle, pressed, selected, disabled, and focus states
  where applicable.
- Use brief, restrained motion as feedback for a user action or state change;
  do not add idle loops.
- Preserve keyboard, touch, accessible labels, and reduced-motion behavior.
- Keep the incumbent design and KARM indigo/brass palette. Do not copy the lime
  treatment.
