# Video 03 — Glass folder cards

## What I asked

I wanted to review the organization reference videos one at a time and decide
how each should be used in the app.

## My direction

Use layered glass folder and file cards with tilt/open motion **only in
Documents/Crystals**.

Video 11 is a repeat of this reference and does not add another requirement.

## Implementation guidance

- Keep this treatment scoped to the Documents/Crystals folder and file browser.
- Build layered cards that make folders and their contained files visually
  distinct; preserve readable names, counts, and available actions.
- Use a restrained glass/material treatment that fits ṚTA by KARM. Keep the
  existing KARM identity and palette; do not copy the reference's colors.
- Use gentle tilt as interaction feedback and an opening transition when a
  folder is selected. Do not add idle motion.
- Make folder selection and open/close actions work with touch and keyboard as
  well as pointer input. Respect reduced-motion preferences.
- Do not apply this card treatment to unrelated screens.
