# Video 04 — Bar and line charts

## My question and answer

**Question:** Which chart visuals from this dashboard reference should be used?

**My direction:** Borrow bar and line chart visuals where they fit, using KARM
colors.

## Implementation guide

- Use bars or lines only for suitable existing data and comparisons.
- Keep axes, units, labels, and series understandable; do not invent values to
  fill a chart.
- Recolor the treatment with the incumbent KARM palette rather than copying the
  reference's green.
- Preserve responsive behavior and accessible descriptions.
- Do not add extra tooltips: the user declined that addition for video 12, which
  repeats this chart direction.
