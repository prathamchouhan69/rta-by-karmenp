# KARM organization reference videos

This folder contains the 14 reference clips and the implementation guidance
you approved while reviewing them individually. Each numbered folder contains
the cropped reference as `reference-crop.mp4`, a `preview.gif`, and an
`implementation-guide.md` with the question, your direction, and guidance for
using it in the app.

The clips are trimmed and cropped to show the referenced design or interaction;
browser chrome, desktop panels, and taskbars are excluded. The guide records
approved direction, not a claim that a feature has already been implemented.
Keep the existing RTA by KARM design and colors; treat these as focused
upgrades, not a replacement design.

## Important decisions

- Videos 11 and 12 are separate recordings that closely repeat videos 3 and 4;
  they are not exact duplicate files or evidence of a playback glitch.
- Do not borrow the references' lime/green palette; keep KARM indigo and brass.
- Do not add chart tooltips for video 12.
- Keep particle effects still until interaction, except for a genuine active
  loading/waiting state.
- Do not invent screens, metrics, severity categories, or business data to force
  a reference into the app. Use clearly marked mock data only when explicitly
  useful for a demo.
- Preserve the previous RTA by KARM design. Apply these directions as targeted
  enhancements only on matching existing surfaces.
