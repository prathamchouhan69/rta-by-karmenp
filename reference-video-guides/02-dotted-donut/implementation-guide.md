# Video 02 — Dotted donut and time filter

## My question and answer

**Question:** Should the dotted donut and its time-range interaction be used
in the app?

**My direction:** Use the dotted donut-chart style and time-range filter
interaction where appropriate.

## Implementation guide

- Use the dotted donut only for a real breakdown that belongs on the current
  screen; keep segments and labels legible.
- Make selecting a segment filter the related visible data, and provide a clear
  way to restore the full view.
- Add a time-range selector only when the chart has date-based values to filter.
- If illustrative mock history is used for a demo, label it as demo data and not
  live business activity.
- Retain KARM colors, accessible names, keyboard/touch operation, and reduced
  motion.
