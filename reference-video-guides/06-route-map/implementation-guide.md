# Video 06 — Routes map

## My question and answer

**Question:** Where should the map-tile visual and navigation interaction be
used?

**My direction:** Use the map tile visual and navigation interaction in
**Routes only**.

## Implementation guide

- Scope map tiles, route selection, and navigation affordances to an existing
  Routes surface.
- Use route/location data already supported by the product; do not place a
  decorative map on unrelated screens.
- Keep the selected route and navigation action understandable without relying
  on color alone.
- Preserve touch/keyboard support and the existing design system.
