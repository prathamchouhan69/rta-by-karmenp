# KARM OS — Document Matrix

This matrix documents the 13 supported primary document kinds and related accounting documents in KARM OS.
All documents are synchronized directly with Zoho Books. Calculations (totals, GST splits, round-offs) are performed exclusively by Zoho Books.

| Document Kind | Zoho Books Endpoint | Operations | Status Actions | Terms & Conditions |
|---|---|---|---|---|
| Invoices | `/invoices` | List, View, Create, Edit | draft, sent, void, open | 3 sets (Standard, Fast Pay, Retention) |
| Estimates / Quotes | `/estimates` | List, View, Create, Edit | draft, sent, accepted, declined | 3 sets (Standard 8-clause, Turnkey, Supply-only) |
| Sales Orders | `/salesorders` | List, View, Create, Edit | draft, open, closed, void | 3 sets (Dispatch, Staged, Advance) |
| Delivery Challans | `/deliverychallans` | List, View, Create, Edit | draft, delivered | 3 sets (Standard, Site Transfer, Returnable) |
| Credit Notes | `/creditnotes` | List, View, Create, Edit | draft, open, closed, void | 3 sets (Rate Adjustment, Quantity Return, Quality Defect) |
| Customer Payments | `/customerpayments` | List, View, Create | recorded | 3 sets (NEFT, RTGS, Cheque) |
| Purchase Orders | `/purchaseorders` | List, View, Create, Edit | draft, open, billed, cancelled | 3 sets (FOB, Ex-Works, Site Delivery) |
| Bills | `/bills` | List, View, Create, Edit | draft, open, paid, void | 3 sets (Net 30, Net 45, Immediate) |
| Vendor Credits | `/vendorcredits` | List, View, Create, Edit | draft, open, closed | 3 sets (Vendor Return, Rate Difference, Rebate) |
| Vendor Payments | `/vendorpayments` | List, View, Create | recorded | 3 sets (Direct Transfer, Auto-Debit, Bank Advice) |
| Expenses | `/expenses` | List, View, Create | recorded | 3 sets (Direct, Site Fuel, Freight) |
| Journals | `/journals` | List, View, Create | draft, published | 3 sets (Depreciation, Month-End, Rectification) |
| Bank Transactions | `/banktransactions` | List, View, Create | uncategorized, categorized, matched | 3 sets (Reconciliation, Bank Sweep, Interest) |

## Statutory & Money Rules
- **PDF Generation**: PDFs are always fetched directly from Zoho Books via the `/pdf` route; the app never generates an invoice PDF locally.
- **Numbering**: Document numbers are generated by Zoho Books auto-numbering sequencers, never chosen by KARM OS.
- **Terms & Conditions**: Quotations include the statutory eight clauses covering price escalation, delivery delays, demurrage, payment terms, testing, force majeure, warranty, and jurisdiction.
