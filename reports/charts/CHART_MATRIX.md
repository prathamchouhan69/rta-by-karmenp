# Chart matrix

The gallery establishes the shared visual grammar. Tier A uses depth-like WebGL-ready
geometry; Tier B uses accessible SVG/HTML fallback with the same glass and parallax shell.

| Preset | Tier | Source |
|---|---|---|
| Vertical bars; line tubes; donut flower; treemap blocks; heatmap field; scatter constellation | A | Zoho values |
| Sankey flow; circle packing; India tile grid; KPI gauge; calendar heatmap; Gantt depth lanes | B | Zoho values |

All chart cards must expose a real table and CSV export when expanded into the full gallery.
