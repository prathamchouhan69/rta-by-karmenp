=== S5: CORS Refuses Another Origin; No Wildcard with Credentials ===

Proxy (server.mjs:91-100):
- Checks Origin header against config.env.APP_ORIGIN
- If origin !== APP_ORIGIN: returns 403 ORIGIN_NOT_ALLOWED
- If origin matches: sets Access-Control-Allow-Origin to that origin (not wildcard)
- Sets Vary: Origin

Gateway (server.mjs:469-479):
- Checks Origin against settings.appOrigin
- If origin !== allowedOrigin: returns 403 ORIGIN_NOT_ALLOWED
- If origin matches: sets Access-Control-Allow-Origin to that origin
- Sets Vary: Origin
- Sets Access-Control-Allow-Headers, Access-Control-Allow-Methods
